# Simple-Login-Webpage
This is a simple login webpage that I created as a reusable codebase for several websites. This README will be updated over time as I learn how to write clear, concise documentation. 

AI Use Disclaimer:
This repo doesn't use AI, not even in the codebase. I know it may seem strange not to use AI today, and I agree it would be much more efficient, however, as a new developer, I think it's important to learn the old-fashioned way on how to write code and organize my files. To create this, I used free resources online, such as YouTube tutorials and documentation from given tools, like Supabase. 

Features:
- Minimalist UI using HTML/CSS
- User Auth with Supabase
- Optional: Email Domain Authentication - only allowing certain organizations to sign up and log in. E.g. in this case, @northwestern.edu emails only. This is good for company-specific or simply organization-specific websites, however, is not needed.
